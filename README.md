# ديوان إسلام — نشر الموقع مجانًا على GitHub Pages

هذا الملف يشرح خطوة بخطوة كيف تنشر موقع «ديوان إسلام» على استضافتك الخاصة مجانًا باستخدام GitHub Pages، دون أي اعتماد على أي منصة أخرى.

## ما المطلوب

- حساب GitHub مجاني.
- خطة GitHub المجانية تشترط أن يكون المستودع (Repository) **عامًا** لتعمل خدمة Pages عليه. أي أن موقعك سيكون **متاحًا للجميع** على الإنترنت، وملفات المصدر في المستودع ظاهرة لأي شخص. هذا طبيعي لموقع عام، لكن لا تضع في المستودع أي شيء خاص.
- لا توجد أي تكاليف: الاستضافة والنطاق (username.github.io) مجانيان.

## الخطوة 1: إنشاء حساب GitHub

1. افتح https://github.com واضغط Sign up.
2. أدخل بريدك الإلكتروني واختر كلمة مرور واسم مستخدم، وأكّد البريد.
3. اختر الخطة المجانية (Free).

## الخطوة 2: إنشاء المستودع

1. بعد تسجيل الدخول، اضغط علامة + أعلى الصفحة ثم New repository.
2. في خانة الاسم اكتب مثلًا: diwan
3. اختر Public (إلزامي للخطة المجانية).
4. لا تُفعّل أي خيار إضافي، واضغط Create repository.

## الخطوة 3: رفع ملفات الموقع

1. فكّ ضغط ملف zip الذي معك على جهازك. ستجد بداخله:
   - index.html — الصفحة الرئيسية
   - مجلد assets — ملفات الموقع (البرمجة والخطوط والقصائد والصورة)
   - .nojekyll — ملف فارغ مهم: يمنع GitHub من معالجة الموقع بنظام Jekyll الذي قد يتجاهل بعض الملفات. احرص أن يُرفع مع باقي الملفات (قد لا يظهر في مستكشف الملفات لأنه يبدأ بنقطة).
2. في صفحة المستودع على GitHub اضغط Add file ثم Upload files.
3. اسحب كل محتويات المجلد المفكوك (index.html ومجلد assets وملف .nojekyll) إلى الصفحة. تأكد أن assets يُرفع كمجلد كامل بمحتوياته (نحو 150 ملفًا). إن تعذّر رفع المجلد دفعة واحدة، ارفع ملفات assets على دفعتين أو ثلاث داخل المجلد نفسه (افتح مجلد assets بعد رفعه أول مرة ثم Upload files بداخله).
4. اضغط Commit changes وانتظر اكتمال الرفع.

## الخطوة 4: تفعيل GitHub Pages

1. من صفحة المستودع افتح Settings (أعلى اليمين).
2. من القائمة الجانبية اختر Pages.
3. تحت Build and deployment وفي خانة Source اختر Deploy from a branch.
4. في Branch اختر main ثم اختر المجلد / (root) واضغط Save.
5. انتظر دقيقة أو دقيقتين، ثم حدّث الصفحة: سيظهر لك رابط موقعك بالشكل:
   https://USERNAME.github.io/diwan/
   (USERNAME هو اسم المستخدم الخاص بك، وdiwan هو اسم المستودع الذي اخترته.)

## الخطوة 5: مشاركة الموقع

- شارك الرابط كما هو. كل الروابط الداخلية تعمل بنظام الهاش (#) مثل ‎#/poet/106، لذلك تعمل الروابط المباشرة لأي قصيدة أو شاعر حتى بعد إعادة التحميل، دون أي إعدادات إضافية.

## ملاحظات تقنية

- كل المسارات داخل الملفات نسبية (تبدأ بـ ./) فتعمل تلقائيًا تحت مسار المستودع الفرعي /diwan/ دون تعديل.
- الموقع يعمل بالكامل في متصفح الزائر: البحث والمفضلة وإعدادات القراءة والكشيدة والخطوط كلها محلية. إعدادات الزائر ومفضلته تُحفظ في متصفحه (localStorage) وتبقى بعد إغلاق الصفحة.
- خطوط جوجل الاختيارية تُحمّل من الإنترنت عند اختيارها؛ باقي الخطوط الأربعة مضمّنة في الملفات وتعمل دون اتصال بأي خدمة خارجية.
- التحديث مستقبلًا: لأي تعديل، ارفع الملفات الجديدة بنفس الطريقة (Upload files) وسيتحدث الموقع خلال دقائق.

## ماذا لو أردت مستودعًا خاصًا؟

الخطة المجانية لا تتيح Pages لمستودع خاص. البدائل المجانية التي تقبل المشاريع الخاصة: Netlify وCloudflare Pages — لكن الشرح هنا مخصص لـ GitHub Pages كما طلبت.
